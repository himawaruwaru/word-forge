# Word Forge 派生語ドリル

帰国生入試の英語に出る「派生語」問題（提示語の形を変えて、文の空所に入れる）を、7問3分で解くドリルです。

- 140問（予想問題 Set 1〜10、本番型 Set 11〜20）
- 苦手な型（不規則・接頭辞・複数形・時制・似た形）の分析
- 間違えた問題は「復習」に入り、2回続けて正解すると抜ける
- レベル・バッジ・テーマの解放
- 記録はこのブラウザにだけ保存（サーバーには送りません）

## 使い方

ブラウザで開くだけです：https://himawaruwaru.github.io/word-forge/

## 作り方

エンジニアではない保護者が、娘の受験勉強のために Claude Code（Vibe Coding）で作りました。HTML 1ファイルで動きます。
